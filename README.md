# Видеонаблюдение на участке — комплект и схема

Одностраничный расчёт системы видеонаблюдения для загородного участка: подбор оборудования,
схема расстановки камер, ожидаемая детализация по дистанциям и настройки после монтажа.

**Страница:** https://zoologov.github.io/ip-cctv/

## Конфигурация

| | |
|---|---|
| Камеры | 2 × 8 Мп на домике охраны у ворот, 2 × 4 Мп на одной сосне |
| Запись | круглосуточно на локальный диск, без облака |
| Регистратор | Dahua DHI-NVR2108HS-8P-4KS3, 8 каналов, 8 портов PoE |
| Удалённый доступ | 4G-роутер, P2P через приложение DMSS, белый IP не нужен |
| Температурный диапазон уличной части | −40…+55 °C |

## Устройство страницы

Один файл `index.html` без зависимостей и сборки. Вся вёрстка, стили и скрипты внутри.

- отметки о купленных позициях сохраняются в `localStorage` браузера;
- ёмкость диска переключается кнопками, суммы и глубина архива пересчитываются;
- сектора обзора на схеме строятся скриптом из массива `CONES`;
- позиции без ссылки на конкретный товар скрипт помечает тегом «цена оценочная»;
- есть тёмная и светлая темы (по системной настройке) и стили для печати.

## Локальный просмотр

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Или просто открыть `index.html` двойным щелчком — внешних запросов страница не делает.

## Правки

Цены и количества живут прямо в атрибутах строк таблицы:

```html
<tr data-id="cam8" data-group="core" data-qty="2" data-price="9575">
```

Итоги считаются из этих атрибутов, отдельно править суммы не нужно. Группы: `core`, `mat`, `opt`.
Расход на запись задан константой `GB_PER_DAY` в скрипте, варианты диска — в объекте `DISKS`.
Чтобы позиция считалась проверенной, в её ячейку добавляется ссылка `<a class="buy">`.

## Оговорки

Шесть основных позиций — цены по карте Ozon, проверены вручную в июле 2026 года, со ссылками
на конкретные товары. Монтажные материалы и дополнения посчитаны оценочно.
Схема условная, без масштаба и привязки к местности: расстояния от сосны до построек у берега
на местности не измерялись, а от них зависит, что камеры реально увидят ночью.
