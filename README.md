# Видеонаблюдение на участке — комплект и схема

Одностраничный расчёт системы видеонаблюдения для загородного участка.
Источник правды по моделям, ценам, схеме и тексту — файл `index.html`.
Этот README только описывает устройство репозитория и как править страницу;
цифры и формулировки комплекта сюда не копируем, чтобы не разъезжались.

**Страница:** https://zoologov.github.io/ip-cctv/  
**Репозиторий:** https://github.com/zoologov/ip-cctv

## Конфигурация (кратко)

Соответствует текущему `index.html`:

| | |
|---|---|
| Камеры | 2 × 8 Мп на левой стене домика охраны у ворот (К1, К2), 2 × 4 Мп на одной правой сосне (К3, К4) |
| Трасса к сосне | воздушная на стальном тросе, два кабеля в одной гофре |
| Запись | круглосуточно, программное зеркало «Резервный диск», 2 × HDD в двух отсеках |
| Регистратор | Dahua DHI-NVR5208-8P-EI (не Lite NVR2208 и не однодисковый NVR2108HS) |
| Удалённый доступ | 4G-роутер, P2P через DMSS, белый IP не нужен |

Модели камер/дисков/роутера/кабеля, ёмкость HDD, глубину архива и суммы смотри только на странице.

## Устройство страницы

Один файл `index.html` без зависимостей и сборки. Вся вёрстка, стили и скрипты внутри.
Деплой: `.github/workflows/pages.yml` → GitHub Pages.

Страница разбита на три раздела с якорями и липким меню:

1. `#scheme` — схема и объяснение  
2. `#order` — оборудование для заказа  
3. `#install` — комментарии по монтажу  

- отметки о купленных позициях — `localStorage` (`STORE_KEY` в скрипте);
- сектора обзора на схеме — массив `CONES`;
- позиции без `<a class="buy">` скрипт помечает тегом «цена оценочная»;
- глубина архива считается из `DISK_TB` и `GB_PER_DAY`;
- темы светлая/тёмная — через `prefers-color-scheme`, плюс стили для печати.

## Локальный просмотр

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Или открыть `index.html` напрямую: страница сама по себе ничего не запрашивает
(ссылки Ozon открываются только по клику).

## Правки

Цены и количества — только в атрибутах строк таблицы в `index.html`:

```html
<tr data-id="…" data-group="core|mat|opt" data-qty="…" data-price="…">
```

Итоги (`core` + `mat` = базовый комплект, плюс `opt` = со всеми дополнениями)
считаются из этих атрибутов, суммы в ячейках и в шапке править руками не нужно.
У зеркальных дисков `data-qty="2"` при одинаковой цене за штуку.
Проверенная позиция = есть ссылка `<a class="buy">` на товар.

При смене комплекта сверяй связанные места на странице: таблицу камер, схему/`CONES`,
кабельную трассу, блок про зеркало, список заказа и предупреждения в конце —
не только строку `data-price`.

## Ревизия

Дата ревизии на странице — дата сверки цен, не дата сборки. Она задана вручную
в трёх местах `index.html`: блок `.meta`, подвал (`.rev`) и оговорка под списком
для заказа. При пересмотре цен обновляй все три одинаково.

Хэш коммита: плейсхолдер `__COMMIT_SHA__` в подвале подставляет workflow при деплое.
Локально скрипт заменяет незаменённый плейсхолдер текстом «локальная копия».
